# VoiceGuard 실제 서비스 출시 가이드

## 1. 핵심 기술 아키텍처
1. **온디바이스 실시간 감지**: `AVAudioEngine`으로 2048 샘플 단위로 읽어 RMS(dB), ZCR, Spectral Flux, F0 피치를 계산합니다.
2. **2-Stage VAD(배터리)**: 1단계는 샘플 1/4만 쓰는 저전력 RMS 에너지 게이트이고, 게이트를 통과한 프레임에만 자기상관 피치·스펙트럴 분석을 수행합니다. 게이트 임계는 트리거 임계보다 2dB 낮게 잡아 경계 프레임 손실을 막습니다.
3. **Pre-Roll 링버퍼(3~15초)**: 격양이 감지된 뒤 녹음을 켜면 앞부분 핵심 발화가 잘리므로, 최근 N초를 메모리에만 순환 보관했다가 트리거 시 파일 앞부분에 이어 붙입니다.
4. **세션 복구**: 인터럽션(전화·알람)·경로 변경(에어팟)·미디어 서비스 리셋·엔진 구성 변경 시 자동 재시작합니다. 진행 중 녹음은 복구 직전에 확정 저장해 파일 손상을 막습니다.
5. **녹음 보안**: 모든 `.m4a`와 `index.json`에 `FileProtectionType.completeUnlessOpen`, 앱 잠금(`LocalAuthentication`)으로 녹음함 접근을 제한합니다.
6. **분석 리포트**: 피크/평균 dB, 최대 F0, 격양 구간 타임라인(0.5초 음량 엔벨로프)을 저장하고 상세 화면에서 타임라인·공유를 제공합니다.
7. **고도화 로드맵 (v1.2+)**:
   - `CreateML` / `CoreML` 음성 감정 분류 모델(Calm / Raised / Angry)을 `VoiceGuardCore`에 결합해 고성 없는 냉소적 어조까지 정밀화
   - `Live Activities` / Dynamic Island로 백그라운드 감지 및 자동 녹음 상태 실시간 표시
   - 연속 고음량 환경(예: TV 상시 시청)에서 게이트가 열린 채 유지되는 특성을 완화하는 환경 분류기

## 2. App Store 심사 대응 전략
- **백그라운드 오디오(`UIBackgroundModes: audio`)**: 애플은 무단 백그라운드 녹음을 엄격히 심사합니다.
  - 앱 실행 시 사용자가 명시적으로 "감지 시작"을 눌러야 동작하도록 설계(현재 구현 완료).
  - 상태바 주황색 마이크 인디케이터와 "평상시 미저장 · 온디바이스 처리" 안내 화면을 심사 영상에 명확히 포함.
- **Face ID(`NSFaceIDUsageDescription`)**: 생체 정보는 기기 밖으로 나가지 않으며 앱이 저장하지 않는다는 문구를 Info.plist와 설정 화면에 명시했습니다.
- **데이터 보호**: `completeUnlessOpen` 등급 사용 사실과 "기기 잠금 시 복호화 키가 내려간다"는 설명을 개인정보 처리방침에 포함합니다.
- **법적 고지**: 대화 당사자 간 녹음 목적임을 최초 안내 및 설정 화면에 명시.
- **배터리 주장 주의**: 앱 내 절약 수치는 **연산량 모델 기반 추정치**입니다. App Store 설명에는 "2단계 분석을 게이트로 제한해 연산량을 줄인다"는 표현을 쓰고, 실측 전력 절감 수치를 마케팅 문구로 쓰지 않습니다.
